For GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html and manifest.json to the repository root.
3. In repository Settings > Pages, publish from the main branch / root.
4. Open the published website in Chrome.
5. Chrome menu (three dots) > Add to Home screen.
